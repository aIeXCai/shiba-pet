# 贱柴桌宠 · Shiba Pet

> 一只写实、眯眼、坏笑、会走、会摔、还会记仇的 macOS 柴犬桌宠。

一个跑在桌面上的柴犬桌宠。透明无边框窗口常驻置顶，可以随手拖着走、拎起来甩、反复骚扰，它会用一整套表情和动作回敬你。

技术栈：**Tauri 2 + Vite 6 + TypeScript**，动画由纯 CSS/JS 状态机驱动，全部素材为逐帧绘制并抠好的透明 PNG（共 450 张）。

## 效果与设计

当前默认关闭所有自主位移：柴犬会留在你放置的位置，只在原地切换待机姿势。想要它自己跑，可以拖动它——方向和速度决定它是小碎步、狂奔、急刹还是被拎起来。

运行时使用以原写实动作素材为母版转换的 **`flat-cartoon-v1` 扁平卡通角色**，共包含：

| 素材类型 | 帧数 | 用途 |
| --- | --- | --- |
| 基础动作帧 | 22 | 站立、坐、趴、翻身、装死等 |
| 姿态桥接帧 | 12 | 姿势之间的逐帧过渡 |
| 拖动连续帧 | 15 | 起步、碎步、狂奔、急刹、停稳 |
| 高频待机衔接帧 | 20 | 无硬切倒放 |
| 后脚挠耳循环帧 | 4 | 挠耳朵循环 |
| 拎起/悬空/坠落/回弹帧 | 36 | 全套离地演出 |

写实母版素材继续保留在 `references/`，用于校对体型、姿势与表情，不再直接作为运行时图片。

### 动作衔接

站立→坐下、坐下→趴下、趴下→翻身现在走逐帧绘制的专用桥接动画，反方向切换会倒序播放，跨多个姿态时自动串联。其余待机姿势用双图层柔和过渡；走路/狂奔有专用起步、加速、停止桥接帧。

拖动动作使用 15 张固定朝向的连续帧。走路与狂奔采用**进入/退出双阈值**（速度滞回），避免速度临界点反复闪烁；突然反向时会先播完整刹车，再翻转到新的移动方向。

## 核心玩法

**拖它，它自己走。**

- 轻轻左右拖 → 四帧交替小碎步，保持默认欠揍脸
- 快速拖 → 伸腿/收腿狂奔帧，耳朵后压
- 突然反向 → 独立急刹姿势，叠加身体倾斜与屁股甩动
- 向上拖 → 根据原姿势连续离地，进入按抓取位置区分的悬空循环
- 松手 → 一次性坠落帧、落地压扁、弹起、恢复站立
- 拖太久 → 抱住鼠标的抗拒姿势，继续拖会装死
- 反复左右晃 → 蚊香眼、吐舌，并给出"呕"的反馈

## 表情模板

默认就欠揍：眼睛半眯、一边眉毛略高、嘴角歪向一侧、一只耳朵竖起另一只微微向后、头略微前伸带审视感，偶尔吐出一点舌尖。被发现偷看会立刻转开视线。

"欠揍程度"驱动斜眼、回头、露舌等完整表情姿势，以及彩蛋和嘲讽台词频率——**不在原画上叠加悬浮五官**，所有表情都是画出来的完整帧。

## 姿势库

**日常待机**

- 正坐着斜眼看主人
- 趴下，把下巴压在前爪上
- 背对主人，只回头露出半张脸
- 舔爪子（4 帧舌头与头部局部循环）、挠耳朵、追尾巴（咬住尾巴 12 张等角度帧连续转圈，固定旋转锚点）
- 四脚朝天睡觉并轻微呼吸抽动
- 把头藏进尾巴里

**互动反馈**

- 点头部：前两次加亲密度，斜眼但嘴上强装嫌弃
- 头部来回抚摸：识别真实往返轨迹，逐步压耳闭眼；持续 3 秒后主动回蹭，停止后倒序恢复并冷漠停顿
- 连续点头部：第 1～2 次斜眼忍耐、3～4 次半飞机耳、5～6 次完全飞机耳抬爪、7～8 次伸爪推开并举"别摸了"、第 9 次咬住光标再吐回；忍耐值自动衰减
- 点屁股：猛回头，露出"你有病吧"的脸
- 摸下巴：眯眼享受，停止后恢复冷漠
- 拖尾巴：原地转圈追鼠标
- 长按：被压成一块柴犬饼

## 桌面行为与彩蛋

- 沿屏幕底部巡逻、读取全局鼠标位置追逐、报复追逐与偷走光标（均已实现，按产品设定默认关闭）
- 屏幕边缘探头
- 推动桌面上的小玩具
- 躲到窗口后面只露眼睛（视觉演出已实现，尚未识别真实应用窗口）

**稀有彩蛋**：戴墨镜走猫步 · 突然变成长条柴犬 · 偷偷掏出手机刷几秒 · 主人加班时递咖啡然后自己喝掉 · 很久没操作时检查主人是否"还活着" · 凌晨给自己盖小被子 · 连点太多次后举"别摸了"的牌子

## 性格系统

心情（开心/无聊/困倦/生气/得意）、亲密度、体力、记仇值四项状态持久化保存：

- 亲密度决定它主动追鼠标还是看到就跑
- 体力决定巡逻/追逐资格，以及睡觉、躺平、装死的频率
- 记仇值由骚扰行为累积，驱动延迟报复
- 晃晕后会在 90–210 秒后读取全局光标位置，主动冲刺、扑咬并短暂偷走光标

## 技术实现

**窗口层**（`src-tauri/tauri.conf.json`）

透明、无装饰、无阴影、不可缩放、220×220 固定尺寸、`alwaysOnTop`、`skipTaskbar`、跨工作区可见、`acceptFirstMouse`——保证点击一次就能抓住它，而不是先激活窗口。

**动画层**（`src/pet/controller.ts`，约 1.2k 行）

一个显式状态机管理姿势、移动、悬空、交互四类状态：

- 桥接动画入队与串联，支持正/反向播放
- 速度滞回（进入/退出双阈值）避免临界抖动
- 交互优先级高于桥接，鼠标介入时约 150ms 快速收势
- 非循环姿势完成桥接后停在末帧，不回退旧静态图

**素材层**（`public/assets/shiba/manifest.json`）

动作清单驱动，44 条运行时状态切换、105 张运行帧全部经过连续性审计。审计脚本 `scripts/audit_animation_continuity.py` 会输出逐路径接触表、相邻帧轮廓位移数据和循环首尾风险排序。

## 开发运行

需要 Node.js、pnpm、Rust 和 macOS Command Line Tools。

```bash
pnpm install
pnpm desktop      # 启动桌面应用（Tauri dev）
```

其他命令：

```bash
pnpm dev          # 只在浏览器预览
pnpm build        # 构建前端
pnpm bundle:mac   # 打包 macOS 应用（.app + .dmg），产物在 src-tauri/target/release/bundle/
```

## 素材组织

```text
public/assets/shiba/
├── sprites/              已抠好的透明 PNG，程序直接使用
│   ├── cartoon-v1/       当前动作帧、姿态桥接
│   │   ├── idle-transitions-v1/
│   │   ├── locomotion-v1/
│   │   └── lift-v1/
│   ├── pixel/
│   └── v2/
├── sources/              绿幕源图（cartoon-v1 卡通动作总表、基础姿势、桥接总表）
├── references/           原始表情参考与角色基准图
└── manifest.json         动作清单
```

## 实现原则

- 只有动作、触发条件和视觉反馈均达到标准才勾选 `[x]`
- 临时 CSS 形变或复用旧姿势只能标记为"部分完成"
- 每补齐一项，同时更新清单、素材清单和构建验证
- 不以抢夺系统输入、长期遮挡按钮等方式影响正常工作
